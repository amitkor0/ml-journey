## How a module gets marked done

A module is `done` when all four are true:

1. Every lesson in the module has notes in `notes/<module-slug>/`.
2. The module's exercises are reimplemented by hand in `notebooks/<module-slug>/` — not copied.
3. Any listed project is built and has a README explaining the problem, the approach, and the result.
4. The module's exit-gate questions in the curriculum README are answered in `notes/<module-slug>/review.md`.
